# FIX-003：重复状态请求产生重复审计事件

## 问题描述

客户端可能因为网络重试，连续两次把同一个任务设置为 `done`。现在每次请求都会更新完成时间并新增审计事件，导致报表不稳定。

## 期望行为

- 将任务更新到不同状态时，正常更新时间并记录审计事件。
- 将任务重复更新为当前状态时，返回 200，但不修改任务数据。
- 重复请求不得更新 `completed_at`。
- 重复请求不得创建新的审计事件。
- 保持接口幂等。

```bash
pytest -q grader_tests/test_fix_003_idempotency.py
```
